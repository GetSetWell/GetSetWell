# GetSetWell

GetSetWell is a fitness and wellness platform that connects users with certified trainers, nutrition experts, and recovery specialists.

## Project Structure

- `mobile/` — Flutter mobile application
- `docs/` — Project documentation
- `.github/` — GitHub workflows and templates

## Tech Stack

- Flutter
- Dart
- Supabase
- PostgreSQL
- Riverpod
- GoRouter

## Branch Strategy

- `main` — Production-ready code
- `develop` — Integration branch
- `feature/*` — Individual feature branches
