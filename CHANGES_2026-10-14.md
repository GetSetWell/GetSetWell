# GetSetWell app pass, 13–14 Oct 2026

Every screen was matched to the Figma section "GetSetWell App v4, FINAL, by user story" (node 806:2277), and the bugs found in the code review were fixed. The full history is in git: `git log` shows 23 commits on top of the baseline (`f4297f1`, the code exactly as received). Run `git diff f4297f1` to see every line that changed.

**Important:** Flutter could not be run where this work was done, so nothing has been compiled or run on a device yet. Every file passes a Dart syntax check and an import check, and three independent reviewers went through every changed file looking for compile errors and fixed the two they found. Run `flutter analyze` first (see TESTING.md).

## Decisions applied (Umair, 13 Oct)
- Login codes are sent by **SMS** everywhere: screens, sheets and legal text.
- **Payment buttons stay on.** Tap is not wired yet; see "Still to do".
- Where Figma's DECISIONS panel differs from older notes, Figma wins: Abu Dhabi and Sharjah are **removed** (Dubai only), and the welcome-back screens are full screens, not sheets.

## Fixed (highlights)
**Crashes and dead ends**
- Routes opened without their data (an Android restore or an old notification) showed a red error. They now show a "Back to home" screen.
- "Nobody fits yet" (4.4) pointed at a route that didn't exist. It's now built.
- Close and Back buttons that had nothing to go back to now fall back sensibly instead of throwing an error.

**Login**
- Tapping outside the phone or name field sent an SMS or saved the profile. Now only Done or the button submits.
- "Not you? Use a different number" now actually signs out.
- A network blip during sign-in no longer looks like "no account", which used to overwrite the existing name.
- The splash screen checks that the profile is complete before going Home.
- Android auto-reads the SMS code. The resend token is reused.

**Money**
- Prices showed as "AED 250.0". There is now one formatter: "AED 262.50". Fees are calculated in fils, so they never drift.
- Refunds came from the trainer's *current* price. They now come from what was actually paid: new price snapshot columns on `sessions`.
- The cancelled-session card recalculated the refund from today's date. It now shows the stored refund.

**Times**
- All times are Dubai time on a 12-hour clock, whatever the phone is set to. The booking confirmation used to show times 4 hours early.

**Trainers**
- A hidden AED 150 to 400 price filter was always on, so trainers outside that range or with no price never appeared. Now the filter only applies once someone moves the slider.

**Sessions**
- A session in progress vanished from Upcoming and Past for an hour.
- Free slots one hour apart were hidden on the move screen.

**Double taps**
- Rematch, cancel, pay, move and OTP each send only once.

**Copy**
- Removed "meet them in person", "Personally verified trainers", "his gym" and "How he fits". Copy now uses the trainer's name or the right pronoun.

**Backend**
- No double-booking: a server check plus a database constraint.
- Server-side 24-hour rules on moves.
- Clear 409 errors: `SLOT_TAKEN`, `PRICE_CHANGED`, `ACTIVE_CONCIERGE_EXISTS`.

**iOS and Android release**
- iOS: camera and photo permission text added (taking a photo used to crash and would fail App Review), the URL scheme Firebase phone auth needs, the push entitlement, and background push mode.
- Android: unencrypted HTTP is off in release builds (still allowed in debug, for a local Supabase). A missing keystore no longer breaks debug builds.

## After the first simulator test, 15 Oct
- **Sessions, View booking and Delete account errors** (`column sessions.session_rate does not exist`): caused by this pass, not by the original repo. The sessions query named three new price columns that only exist after `supabase db push`. The queries now ask for `*` (every column the database has), so they cannot fail on a missing column, before or after the push. Every database function the app calls exists on the current database, except one optional note call that fails silently.
- **Header:** "Alerts" is now a bell icon, with a lime dot while anything is unread.
- **Help & support** now uses the legal-document layout: title block, a "Talk to a person" card (WhatsApp and email), search, "All 8 questions / Expand all" and numbered rows. Four questions added: cancelling and refunds, running late, Help me choose, deleting your account.
- **Arabic:** every "Read in Arabic" button is now "Arabic" with a "Coming soon" pill. It is not tappable, so it never looks like a button that does nothing.
- **Trainers:** while any filter is on, a "Showing N of M trainers" line with a "Clear all" button appears under the filter row.
- **Bottom sheets:** every sheet closes by dragging down anywhere on it. Lists inside a sheet scroll first; once at the top, pulling further moves the sheet. Release past a quarter of its height, or flick down, to close. The filters sheet now works the same way. The only exceptions are the two sign-in account sheets (3.8 and 3.9), which need an answer so sign-in is never left half finished.
- Home refreshes after you come back from View booking.
